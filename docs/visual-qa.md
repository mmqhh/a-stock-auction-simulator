## 本次发现并修复

1. 供需曲线的 Canvas 长图例在较窄面板中被截断。改为图外的可换行图例，保留详细悬停说明，并约束曲线提示框的位置。
2. 深度表、我的委托、逐笔委托顶部使用单行布局，右侧控件会被隐藏。改为换行，保留所有操作控件。
3. 9:15 只有一个参考价点时，价格点和量柱贴着图表左边框，难以辨认。在起点内侧补画单点和量柱，不新增未来快照。
4. 首次加载缺少 favicon，产生 404 控制台错误。新增本地 SVG 图标。
