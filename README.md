# A股集合竞价模拟器

自由下买单 / 卖单，实时观察它们对集合竞价参考价、匹配量、未匹配量的影响。界面参照同花顺 / 东方财富 / 通达信的集合竞价看盘方式。

## 运行

**一键启动**：双击项目目录下的 `启动模拟器.bat`（或桌面上的“A股集合竞价模拟器”快捷方式）。首次运行会自动安装依赖，随后自动打开浏览器；关闭命令行窗口即停止。

手动方式：

```powershell
npm install
npm run dev      # http://localhost:5173
npm test         # 引擎、图表数据与 DOM 界面回归测试
npm run build    # 生产构建
```

## 功能

- **竞价走势图**：基于开源行情图形库 [HQChart](https://github.com/jones2000/HQChart)（Apache-2.0）的分时图集合竞价模式（2.0 数据格式）
  - 只显示开盘集合竞价时段 9:15–9:25，占页面左侧一列，不显示 9:30 之后的连续竞价区
  - 白线：虚拟匹配价；顶部向下倒挂的柱：未匹配量（红 = 买方剩余，绿 = 卖方剩余）；底部向上的柱：匹配量
  - 叠加层：竞价区时间轴、9:20 撤单截止线、最终开盘价
- **竞价盘口**：按交易所行情揭示规则显示（买一 / 卖一 = 参考价 + 匹配量，未匹配量揭示在买二或卖二，价格栏为空）；右上角“量 / 额”切换显示单量（手）或金额（元，未匹配额按参考价计算），选择会被记住
- **下单面板**：买入 / 卖出、涨停 / 跌停 / 昨收 / 参考价快捷价，下单前的**影响预演**（参考价、匹配量、未匹配量变化以及本单预计成交）
- **委托簿深度**（上帝视角）：每个价位的买卖量、累计买 / 累计卖、可成交量，标出参考价的定价依据
- **供需曲线**：累计买 D(p)、累计卖 S(p)、可成交量 min(D, S)
- **逐笔委托**、**我的委托**（预计 / 实际成交、撤单、下单影响）、**规则说明**
- **背景市场**：多空均衡、抢筹高开、恐慌低开、9:20 前诱多撤单、一字涨停封单、空白盘；活跃度与多空倾向可实时调节，随机种子可复现
- **设置**：股票名称 / 代码、板块（±10% / ±20% / ±5%）、上交所 / 深交所规则、昨收、快照间隔（只模拟开盘集合竞价 9:15–9:25）

## 输入与运行边界

- 数量框仍以“手”为单位。主板、创业板从 1 手起，按整手递增；科创板从 2 手起，按 0.01 手递增，例如输入 `2.01` 表示 201 股。内部订单、匹配量、深度和成交分配统一使用整数股，价格使用整数分。
- 科创板普通限价委托最多 1000 手，数量依据[上交所科创板说明](https://edu.sse.com.cn/tib/qa/c/4866268.shtml)。模拟器不维护持仓，暂不模拟余额不足最低申报数量时的一次性零股卖出。
- 昨收价范围为 0.01–100000 元，随机种子为 0–4294967295 的整数，快照间隔为 1 秒或 3 秒；无效配置在创建模拟前拦截。
- 活跃度设为 0 后停止背景申报与撤单，已有委托保留。关闭期间到期的场景事件跳过，恢复后不补发；开始时活跃度为 0，也不生成初始委托。
- 暂停在 9:15 或任一快照时刻，下单和撤单都会立即更新图表末端。窄窗口会改为纵向布局，面板和设置窗口可以滚动。
- 刷新页面仍会重新开始模拟；盘口“量／额”选择单独保存。

## 开发与验证

- `npm run build` 同时执行 TypeScript 类型检查。`npm test` 包含撮合算法、宽价差候选区间、科创板逐股成交、输入边界、全部场景及 DOM 下单流程回归。
- `src/ui/auctionChartData.ts` 是独立的 HQChart 2.0 数据适配器。DOM 测试用它检查图表数据与盘口一致性；Canvas 实际绘制、浏览器缩放与窄屏视觉布局仍需要浏览器验收。
- HQChart 固定为 `1.1.15929`，直接引用图形模块并独立异步加载。图表包仍较大，升级时需复核内部坐标、窗口分割和销毁接口。
- 撮合候选价格保存为区间及数量，不再按每一分钱展开大数组；引擎数量 API 的单位为股，例如 `sim.placeOrder('B', 1000, 201)` 表示以 10.00 元申报 201 股。

## 撮合规则（src/engine/auction.ts）

1. 可实现最大成交量的价格；
2. 高于该价格的买入申报与低于该价格的卖出申报全部成交；
3. 与该价格相同的买方或卖方至少有一方全部成交。

多个价格满足时：

- 上交所：取未成交量最小的申报价格；仍有多个取中间价（四舍五入到 0.01 元）。
- 深交所：取累计买卖差最小的价格；仍相等时，取最接近前收盘价的价格。

成交按价格优先、时间优先分配。9:15–9:20 可撤单，9:20–9:25 不可撤单。

## 目录

```
src/engine/   撮合引擎、模拟器、背景场景（纯 TypeScript，含单元测试）
src/ui/       界面组件（HQAuctionChart 为 HQChart 封装）
```

> 图表通过 HQChart 官方样式开关 `DisableLogo` 关闭了左下角文字标识，未修改库源码。背景委托由随机模型生成，不代表任何真实股票，仅用于学习集合竞价机制。
